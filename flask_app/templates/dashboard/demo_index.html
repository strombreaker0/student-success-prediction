Supervised Machine Learning Models

This system was developed as a S.Y. B.Sc. Computer Science field project by Asmita Chandram Kumbar (Roll No: SI1161). It employs three complementary algorithms trained on 8 academic behavioral indicators:

  • Logistic Regression • Baseline probabilistic classification with calibrated odds ratios.
  • Decision Tree • Intuitive rule-based segmentation with explainable thresholds.
  • Random Forest (Ensemble) • Robust bagging classifier mitigating variance and overfitting.
Security & Role-Based Access Isolation

Institutional student confidentiality is enforced through multi-layered server-side access controls:

  • Zero Production Data Exposure: Public presentation mode only queries synthetic records.
  • Password Security: Cryptographically hashed with PBKDF2/SHA-256 (16-byte random salt).
  • Protected Write Operations: Add, edit, delete, and bulk CSV uploads require authenticated admin authorization.
